# Contributing to Dynex Sans

Thank you for your interest in contributing to **Dynex Sans**! We welcome community contributions to help improve and expand this typeface ecosystem.

---

## How Can You Contribute?

1. **Reporting Issues:**
   - Rendering bugs or unexpected glyph clipping in specific browsers or operating systems.
   - Kerning discrepancies or vertical alignment issues.
   - Missing unicode character requests.
   
2. **Improving Documentation:**
   - Framework presets, configuration examples, and tutorials for new frameworks in `INTEGRATION.md`.
   - Bug fixes in documentation.

3. **Submitting Pull Requests:**
   - Fork this repository.
   - Create a feature branch: `git checkout -b feature/improvement-name`.
   - Commit your changes with clear messages.
   - Open a Pull Request detailing the changes and reason.

---

## Community Guidelines

By contributing, you agree to adhere to our [Code of Conduct](./CODE_OF_CONDUCT.md).

For questions or assistance, contact **info@dynime.com** or open an issue on GitHub.
